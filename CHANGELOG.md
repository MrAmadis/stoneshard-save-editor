# Changelog

## 1.0.2 — 2026-10-27

- **Unlock tree** works on every skill tree. Before, it was greyed out with "There's no unlock data for this tree yet" on Shields, Axes, Maces, Athletics, Warfare, Archery, Polearms, Survival, Greataxes and Greatmaces. It now opens a closed tree's first row, as reading its first treatise does in the game.

## 1.0.1 — 2026-10-27

- Works on Steam's **modbranch**, the beta branch that mods need. Before, the editor showed "Game files not found" there, so item icons, the item catalog and the Skills tab were unavailable.
- First release on GitHub.

## 1.0.0

- First release, on [Nexus Mods](https://www.nexusmods.com/stoneshard/mods/423).
